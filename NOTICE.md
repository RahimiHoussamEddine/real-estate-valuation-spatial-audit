# Data sources and attribution

## UCI Real Estate Valuation

This project uses the Real Estate Valuation dataset from the UCI Machine
Learning Repository:

- Dataset page: https://archive.ics.uci.edu/dataset/477/real%2Bestate%2Bvaluation%2Bdata%2Bset
- DOI: https://doi.org/10.24432/C5J30W
- Citation: Yeh, I. (2018). Real Estate Valuation [Dataset]. UCI Machine
  Learning Repository.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).

The dataset describes historical market records from Sindian District, New
Taipei City, Taiwan. UCI describes it as a 414-row regression dataset with six
features. Dataset terms remain CC BY 4.0; attribution is required when
redistributing or adapting the data. Raw workbook files are excluded from Git.
This project is independent and is not endorsed by UCI.
